# Cosa Nostra: A Generational Saga

A browser-based mafia dynasty strategy game. Build your crime family from 1946 through the RICO era.

## Play

Open `index.html` in any modern browser, or serve locally:

```bash
cd game-project/cosa-nostra
python3 -m http.server 8080
```

Then visit http://localhost:8080

## Features

- Generational succession — pass the Don title to heirs
- City map with rackets, modules, and rival raids
- Commission diplomacy, laws, and Boss of Bosses
- Auto-save each year (localStorage)
- Street crimes, special operations, influence, and front businesses

## Controls

- **Next Year** — advance time and collect income
- **Space / Enter** — shortcut for Next Year (when no modal is open)
