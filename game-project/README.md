# Cosa Nostra: A Generational Saga

This folder now contains two playable prototypes:

- `index.html` - a polished browser game based on the pasted Cosa Nostra concept.
- `main.py` - the existing Pygame prototype.

## Play the browser game

Open `index.html` in a browser, or serve the folder locally:

```bash
cd game-project
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Browser game features

- Working yearly game loop with income, payroll, laundering, heat, and federal case pressure.
- Recruitable family members with traits, stats, loyalty, promotions, and deaths.
- City map with rackets to buy, raid, guard, and upgrade.
- Rival family pressure and territory theft.
- Legitimate front businesses and political influence tracks.
- Street jobs for emergency cash.
- Local save/load support.
- Win/loss states for clean wealth, city control, federal indictment, and succession collapse.
